# Saltline Ext（SLX）

基于**原版 Saltline**（Felix Rieseberg 用 Claude Fable 5.2 生成的单文件浏览器 FPS）的扩展与汉化版本。原版游戏代码**零逻辑改动**，全部新功能以独立扩展模块（SLX）追加。

> **仅供学习研究。** 原作未附开源许可证，本项目不构成再授权；如权利人提出异议将立即处理。

## 在线游玩 / 本地运行

- 下载 `index.html` 双击即可游玩（约 1.4 MB，无外部资源依赖，可离线）
- 或 `python3 -m http.server` 后打开

## 新增功能（相对原版）

| 功能 | 按键 | 说明 |
|---|---|---|
| 枪械配置切换 | `1` / `2` / `3` | 标准 / SD 消音型（45 发·散布 ×0.72）/ DMR 精准型（15 发·散布 ×0.45·伤害 ×1.6），独立弹药池 + 涂装/配件 |
| 昼夜主题 | `T` 循环 | 黄昏（原版基准）→ 晴天清晨 → 断电风暴 |
| 准星自定义 | `O` 换色 / `N` 中心点 | 5 色 + 中心点开关 |
| 伤害飘字 | 自动 | 弱点橙色 / 击杀红色 |
| 击杀信息流 | 自动 | 右上角滚动播报 |
| 战绩存档 | 自动 | 出击/通关/阵亡/最佳评级/最快用时/累计击毁，标题屏展示 |
| 布局加载 | `M` 循环 / `?seed=` | 港区标准布局 + 变体 α/β（原版 seed 播种，重开生效） |
| 手雷投掷 | `G` | 每次出击 3 枚，弹道+弹跳+范围伤害（TIDEBREAK 机制移植） |
| 调试面板 | `F3` | FPS / 绘制调用 / 状态 / 坐标 |
| 界面汉化 | — | 全部 UI/菜单/提示/对白中文，占位符与格式保持原样 |

设置持久化于 `localStorage("saltline.ext.v1")`，不触碰原版设置键。

## 文件说明

- `index.html`：完整可运行包（原版主脚本逐字节保留 + 追加 SLX 扩展 + 汉化文本替换）
- `slx.js`：扩展模块可读源码（构建时注入 index.html）
- `CHANGES.md`：变更台账（含挂点依据、验证记录）
- `汉化与自检报告.md`：汉化范围与功能自检
- `verify2.mjs`：汉化完整性回归校验器
